## 🛡️ Proyecto destacado · AppSec Security Auditor v1.1

> **Skill para Claude orientada a auditorías preventivas de seguridad de aplicaciones.**

[![AppSec Security Auditor](https://img.shields.io/badge/AppSec-Security_Auditor_1.1-0A7C86?style=for-the-badge&logo=github)](https://github.com/xavibarugasu/xavibarugasu/tree/main/.claude/skills/appsec-security-auditor)

**¿Qué hace?** Ayuda a revisar código y configuración mediante 20 controles de seguridad, referencias a OWASP Top 10 y ASVS, hallazgos con evidencia, priorización de riesgos y propuestas de remediación supervisada.

**Modalidades:** revisión contextual · auditoría de solo lectura · planificación de correcciones · remediación autorizada.

**Automatización complementaria:** GitHub Actions realiza comprobaciones preventivas de indicadores de secretos al recibir cambios en el repositorio. No equivale a una auditoría completa ni ejecuta automáticamente Claude.
