# Plantilla de informe AppSec

## 1. Identificación
Proyecto, repositorio/rama, versión, fecha, evaluador, autorización y modalidad (AUTO-CHECK/AUDITAR/PLAN/CORREGIR).

## 2. Resumen ejecutivo
Contexto, exposición, número de hallazgos por severidad, riesgos prioritarios y limitaciones principales.

## 3. Alcance y metodología
Rutas revisadas, stack, comandos/pruebas realmente ejecutados, exclusiones, accesos disponibles y referencias OWASP verificadas.

## 5. Hallazgos
Para cada hallazgo:
- ID / título / severidad / grado de confianza.
- Ruta(s) y línea(s); referencia de código redactada, sin secretos.
- Condiciones necesarias e impacto.
- Recomendación mínima y alternativas.
- Prueba de validación permitida.
- OWASP Top 10:2025 / ASVS 5.0 solamente si mapeo verificable.

## 7. Riesgo residual
Aspectos no revisados o no verificables, incertidumbre, dependencias externas y pruebas pendientes.

## 8. Conclusiones
Diferenciar hallazgos demostrados de hipótesis. No afirmar que la aplicación es «100 % segura».
